# Contributing

Issues and pull requests are welcome. Explain the problem and the resulting
behaviour. Keep DSP, MIDI and UI changes focused and run the technical checks
described in BUILDING.md. Describe any tests you could not run.

By contributing original application code or project documentation, you agree
to license your contribution under AGPL-3.0-only. You retain your copyright;
no copyright assignment is required. Preserve existing authors' notices. Include
an SPDX licence identifier in new code files. Identify any third-party material
and its licence, and do not submit material you cannot lawfully contribute.

New artwork needs an explicit provenance and licence statement. Do not assume
that this project's CC0 dedication covers other images or fonts.
