# Ruslan Display

Original, unmodified `RuslanDisplay-Regular.ttf` from Google Fonts:
https://github.com/google/fonts/tree/main/ofl/ruslandisplay

Copyright 2011 Oleg Snarsky, Denis Masharov, Vladimir Rabdu.
Licensed under the SIL Open Font License 1.1; see the accompanying `OFL.txt`.

Downloaded on 2026-10-27. Embedded in the application via JUCE BinaryData;
no system-wide font installation is performed. The font supports both Latin
and Cyrillic. The English interface uses Latin glyphs with an old Slavic
display style. Numeric fields and small technical readouts use a system
monospaced fallback for legibility. Distributed builds include the full OFL
notice next to the Standalone executable and inside the VST3 Resources folder.
